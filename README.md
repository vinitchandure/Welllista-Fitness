# Welliesta Fitness Website

The official, modern web application for **Welliesta Fitness** (Amravati, Maharashtra).

A responsive, high-performance web experience built with React 19, Vite, and Tailwind CSS. Features interactive fitness tools, authentic gym gallery slideshows, real Google reviews, smooth scroll-triggered micro-animations, BMI calculator, floating WhatsApp support, and a complimentary 1-Day trial booking flow.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
The compiled, optimized production bundle will be generated in the `dist/` directory.

### 4. Preview Production Build Locally
```bash
npm run preview
```

## 🌐 Deployment on Vercel

This repository is pre-configured for one-click deployment on **Vercel**:

1. Push this project to your **GitHub** account.
2. Sign in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Vercel automatically detects **Vite**:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Click **Deploy**. Your site will be live instantly with a global CDN and automatic SSL.

## 🛠️ Tech Stack & Key Features

- **Frontend**: React 19, Vite, Tailwind CSS v4
- **Icons**: Lucide React & Simple Icons
- **Interactive Tools**: Dynamic metric/imperial BMI Calculator with custom body composition insights
- **Animations**: Compositor-accelerated hardware animations with reduced-motion accessibility support
- **Customer Features**: Member sign-in modal, 20% discount offer modal, direct phone & WhatsApp CTA integration
